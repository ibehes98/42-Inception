Inception

Mapa de la infraestructura de ibeltran. Cada recuadro es una capa: la máquina virtual contiene la red de Docker, y la red contiene los contenedores. Pulsa un servicio para abrirlo.

Máquina virtual

Solo dos puertas abiertas al exterior: 443 (HTTPS) y 21 (FTP).

Red Docker «inception»

Entrada

NGINX Único punto de entrada web, TLS 1.2 y 1.3 puerto 443 Comprobando…

Aplicaciones

WordPress La web principal / Comprobando… Panel de WordPress Entradas, usuarios y ajustes /wp-admin/ Comprobando… Adminer Explorar la base de datos /adminer/ Comprobando… Estadísticas Visitas en tiempo real con GoAccess /stats/ Comprobando… Esta página Web estática en su propio contenedor /static/ Comprobando…

Datos y caché

MariaDB Base de datos de WordPress puerto 3306, solo red interna No accesible desde el navegador
Redis Caché de objetos de WordPress puerto 6379, solo red interna No accesible desde el navegador

Servidor FTP

Sube ficheros a WordPress por FTPS (cifrado obligatorio). Desde la máquina virtual:

lftp -u ibeltran_ftp -e "set ftp:ssl-force true; set ssl:verify-certificate no" ftp://127.0.0.1
